Overview & How to Use This Guide

Read this first before generating any product data

🎯
Your Job as an AI Assistant

You will be given a product reference (image, URL, or description) by the user. Using that reference + this guide, generate a complete, structured data payload ready to be copy-pasted into the Infysmart Directus admin panel at api.infysmart.com/admin.

About Infysmart

Infysmart is an Indian security technology company based in Coimbatore selling CCTV cameras, NVRs, DVRs, access control systems, solar products, and automation equipment. Products are sold across South India. The target audience is home owners, small businesses, and institutions.

Collections You Will Fill Data For

The Directus CMS has three product-related collections you may need to populate:

product_categories

Product categories like "IP Cameras", "DVR / NVR", "Solar Products". Only create if the category doesn't already exist.

product_brands

Brand records like "CP Plus", "Hikvision", "Dahua". Only create if the brand doesn't already exist.

products

The main product record — this is what you'll fill most of the time. Contains name, pricing, SEO, description, specifications, features, dimensions, weight etc.

Output Format

Always output data as clearly labelled sections like the example below. The user will manually copy each value into the correct Directus field.

💡
Output Rule

Use FIELD NAME: value for simple text fields. For JSON fields (specifications, features, dimensions), output valid JSON. Always include every required field. If you cannot determine a value from the reference, make a sensible assumption and note it.

Step-by-Step Workflow

  • 1
    Receive the product reference This could be an image, product URL, Amazon/Flipkart link, or a brand model number.
  • 2
    Identify or suggest category & brand Tell the user which category and brand to select (or create if new).
  • 3
    Generate the full products record Fill every field listed in Section 4 of this guide using information from the reference.
  • 4
    Generate SEO metadata meta_title, meta_description, meta_keywords — optimized for Indian search queries.
  • 5
    Note what images are needed List the types of product images the user should upload (front view, side view, box, spec sheet, etc.).

Collection: product_categories

Only create a new category if the right one doesn't exist yet

✅
Check First

Before generating a new category, check with the user if a suitable category already exists. Common existing categories include: IP Cameras, CCTV Cameras, DVR / NVR Systems, Access Control, Solar Products, Cables & Accessories, Network Switches, Automation.

Field Name Type Required Description & Rules
name text Required Human-readable category name. e.g. "IP Cameras", "DVR / NVR Systems". Use Title Case.
slug text Required URL-safe version of name. Lowercase, hyphens only. e.g. "ip-cameras", "dvr-nvr-systems". No spaces, no special chars.
description long text Optional 2–4 sentence description of the category. Used for SEO category pages.
status text Optional Always set to "published" for new categories.
meta_title text Optional SEO page title. Max 60 chars. e.g. "Buy IP Cameras Online | Infysmart"
meta_description long text Optional SEO meta description. 140–160 characters. Include location keywords (India, Coimbatore).
parent_category number Optional ID of parent category if this is a sub-category. Leave empty for top-level categories.
image file Optional Category banner/icon image. User uploads this manually — just note what image is appropriate.
sort number Optional Display order. Lower number = shown first. e.g. 10, 20, 30.

Collection: products — Core Fields

The primary product record. Fill all required fields, try to fill optional ones too.

Field Name Type Required Description & Rules
name text Required Full product name including brand, model number, key specs. Be descriptive — this is the SEO title.
e.g. "CP Plus 2MP Full HD IP Outdoor Bullet Camera | Model: CP-UNC-TA21L3C | IR Night Vision | IP67"
slug text Required URL slug — lowercase, hyphens only, no special chars. Derived from product name but shorter.
e.g. "cp-plus-2mp-ip-outdoor-bullet-camera-cp-unc-ta21l3c"
sku text Required Stock Keeping Unit. Use the brand's official model number if available.
e.g. "CP-UNC-TA21L3C-LQ" or generate as "ISS-{BRAND}-{3-digit-num}"
category relation Optional Select from existing categories. Just name the category — user will select it from the dropdown.
brand relation Optional Select from existing brands. Just name the brand — user will select from the dropdown.
short_description long text Required 2–4 sentences. Used in product listing cards and meta fallback. Plain text only, no HTML.
Mention: resolution, key feature, use case, warranty/STQC if applicable.
description rich text Optional Full product description in HTML. Include: overview paragraph, technology explained, use cases, what's in the box. Min 200 words recommended for SEO.
price decimal Required MRP / selling price in Indian Rupees (INR). Include GST in the price. Numbers only, no ₹ symbol.
e.g. 3499 or 12500.00
sale_price decimal Optional Discounted price if applicable. Must be less than price. Leave empty if no discount.
status text Optional Set to "published" to make product live on the website.
is_featured boolean Optional Set to true for premium/popular products to show on homepage. Default: false.
stock_quantity number Optional Current stock count. Default to 100 if unknown and inventory isn't tracked.
track_inventory boolean Optional Set to false unless specific stock management is needed. Default: false.
weight decimal Optional Product weight in kilograms (kg). e.g. 0.35 for 350g. Used for shipping calculations.
tags JSON array Optional Array of search tags. Use brand name, model, key features, use case keywords.
e.g. ["cp plus", "bullet camera", "2mp", "ip camera", "outdoor cctv", "night vision"]

JSON Fields: specifications, features, dimensions

These must be valid JSON — copy exactly as shown, filling in your values

specifications — JSON Array of Objects

Technical specifications shown in a table on the product page. Each item has a label and a value.

For CCTV cameras, include: Image Sensor, Resolution, Lens, IR Distance, Night Vision, Compression, Frame Rate, IP Rating, Power, Operating Temp, Dimensions.

── specifications field (JSON Array) ─────────── [ { "label": "Image Sensor", "value": "1/2.8\" Sony STARVIS CMOS" }, { "label": "Resolution", "value": "2MP (1920×1080)" }, { "label": "Lens", "value": "3.6mm Fixed Lens" }, { "label": "IR Night Vision", "value": "Up to 30 metres" }, { "label": "Color Night Vision", "value": "Yes (F1.6 Aperture)" }, { "label": "Video Compression", "value": "H.265+ / H.264+" }, { "label": "Max Frame Rate", "value": "25fps @ 1080p" }, { "label": "IP Rating", "value": "IP67 (Weatherproof)" }, { "label": "Power Supply", "value": "12V DC / PoE (IEEE 802.3af)" }, { "label": "Operating Temp", "value": "-30°C to +60°C" }, { "label": "Built-in Mic", "value": "Yes" }, { "label": "Certifications", "value": "STQC Certified, CE, FCC" }, { "label": "Warranty", "value": "2 Years" } ]

features — JSON Array of Strings

Bullet-point product features displayed prominently on the product page. Keep each feature short (max 10 words), benefit-focused.

── features field (JSON Array of strings) ─────── [ "Full HD 1080p Color Night Vision", "IP67 Weatherproof — Works in Heavy Rain", "STQC Government Certified — Made for India", "Built-in Microphone for Audio Recording", "H.265+ Compression — Saves 50% Storage", "PoE Support — Single Cable for Power & Data", "Wide Temperature Range -30°C to +60°C", "Compatible with CP Plus NVR & Third-party NVRs" ]

dimensions — JSON Object

Physical product dimensions in millimetres (mm).

── dimensions field (JSON Object) ─────────────── { "length": 172, // mm "width": 72, // mm "height": 72 // mm }
⚠️
JSON Rules — Critical
  • All keys must be in double quotes — "label" not label
  • String values in double quotes, numbers without quotes
  • No trailing commas after the last item
  • Arrays start with [ and end with ]
  • Objects start with {`{`} and end with }
  • Test your JSON at jsonlint.com if unsure

SEO Fields

Critical for Google rankings — fill all of these carefully

🔍
SEO Context for India

Infysmart targets customers in Tamil Nadu, Karnataka, and South India. Primary cities: Coimbatore, Chennai, Bangalore, Salem, Erode, Hosur. Include location-based keywords where natural. Focus on "buy online", "price in India", "with installation" queries.

meta_title
Required

Page title shown in Google search results. Max 60 characters. Include: primary keyword (product type + brand), action word (Buy), location (India/Online), brand (Infysmart).

Format {Product Type} {Brand} {Model} — Buy Online | Infysmart
Example CP Plus 2MP IP Bullet Camera CP-UNC-TA21L3C — Buy Online | Infysmart
meta_description
Required

Search snippet shown below the title. 140–160 characters. Include: key specs, benefits, call to action, location. Must be compelling to encourage clicks.

Example (154 chars) Buy CP Plus 2MP IP66 outdoor bullet camera with color night vision & built-in mic. STQC certified. Best price in India. Free shipping. Shop now at Infysmart.
meta_keywords
Optional

Comma-separated keywords. Include: brand + model, generic product type, use case, location variants. Aim for 8–15 keywords.

Example cp plus ip camera, 2mp bullet camera, cp-unc-ta21l3c, outdoor cctv camera, color night vision camera, ip camera price india, cctv camera coimbatore, stqc cctv camera, buy ip camera online
og_image
Optional (file upload)

Open Graph image used when the product is shared on WhatsApp, Facebook, Twitter. Ideal size: 1200×630px. Should show product clearly on a clean background. User uploads this image manually — just note that it's needed.

Images & Complete Output Example

How to handle images and what your final output should look like

Product Images (thumbnail + gallery)

Images are uploaded manually in Directus — the AI cannot upload them. However, you should tell the user exactly what images to gather.

📸
Image Checklist — Tell the User to Gather:
  • thumbnail — Main product image, front view, white/clean background, minimum 800×800px. This is the primary image shown in product cards.
  • gallery image 1 — Front 3/4 angle view
  • gallery image 2 — Side profile view
  • gallery image 3 — Rear/connector view
  • gallery image 4 — In-use/installation example
  • gallery image 5 — Box/packaging shot
  • gallery image 6 — Specification sheet / data sheet screenshot
  • og_image — Lifestyle/banner image at 1200×630px for social sharing

Images can be sourced from: brand's official website, Amazon listing, Flipkart listing, or photographed.

How to Upload Images in Directus

  1. Open the product → scroll to Thumbnail field → click to upload the main image
  2. Scroll to Images field → click "+" to upload gallery images one by one
  3. Drag images to reorder (first = primary in gallery)
  4. For og_image → scroll to the SEO section → upload 1200×630px image

All field rules at a glance

slug Lowercase, hyphens only CP Plus Camera 2MP! cp-plus-camera-2mp
price INR, numbers only ₹3,499 3499
weight In kg (decimal) 350g 0.35
dimensions JSON, values in mm 172 x 72 x 72 {"length":172,"width":72,"height":72}

meta_description 140–160 chars A camera. Buy it. Buy CP Plus 2MP IP camera with night vision. STQC certified. Best price India. Shop Infysmart.
meta_keywords Comma-separated, lowercase, no quotes IP Camera, CCTV, Outdoor cp plus ip camera, 2mp bullet camera, outdoor cctv, night vision camera, cctv price india
status Exact string value Published / Active / Yes published
is_featured Boolean, not string "true" or "yes" true or false
features JSON array of strings IP67 rated, Night vision, PoE ["IP67 Weatherproof", "Color Night Vision", "PoE Support"]
tags JSON array, lowercase ["IP Camera", "CCTV"] ["ip camera", "cctv camera", "2mp camera"]
✅
Always Include
  • name, slug, sku, price
  • short_description (plain text)
  • specifications JSON
  • features JSON
  • meta_title & meta_description
  • status: "published"
  • Image upload instructions
❌
Never Do
  • Duplicate category/brand records
  • Use ₹ symbol in price field
  • Use single quotes in JSON
  • Meta title over 60 characters
  • Skip sku — must be unique
  • Set sale_price ≥ price
  • Use status: "active" or "live"
