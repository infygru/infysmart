Infysmart — Product Upload Quick Guide

How to add a product in Directus CMS with full SEO optimisation

infysmart.com
v1.0 · 2025
Step-by-Step Workflow
1
Login → api.infysmart.com → Collections → Products → + Add Item
2
Fill core fields — Name, SKU, Price, Stock, Short & Long Description
3
Upload images — main image first, then gallery shots (min 800×800 px, JPG/WebP)
4
Fill SEO fields — Meta Title, Meta Description, Meta Keywords, OG Image
5
Add specs & features — structured JSON or bullet list in the specs field
6
Set slug — auto-generated from name, verify it's lowercase, hyphen-separated
7
Set Status → Published and save. Product goes live instantly.
Tip: Always complete SEO fields before publishing. Changing meta_title after indexing can reset Google rankings.
Core Product Fields
name requiredFull product name with brand & model. E.g. Hikvision DS-2CD2143G2 4MP Dome Camera
slug requiredURL identifier — auto-generated. Verify: hikvision-ds-2cd2143g2-4mp-dome
sku requiredInternal product code. E.g. HV-CAM-001
price requiredSelling price in INR (no commas). E.g. 4999
original_price optionalMRP before discount — shows strikethrough & discount %
stock requiredQuantity on hand. Set 0 to show "Out of Stock"
short_description required1–2 lines shown in product cards. Keep under 120 chars.
description requiredRich text — full details, benefits, use cases (300–600 words ideal)
category / brand requiredSelect from dropdown. Affects filters & shop navigation.
tags optionalComma-separated. E.g. CCTV, dome camera, IR night vision. Used as keyword fallback.
is_featured optionalToggle ON to show on homepage Featured Products section
SEO Fields (Critical)

meta_title

50–60 characters. Include primary keyword + brand.
Good: Hikvision 4MP Dome Camera – Buy Online | Infysmart
Bad: Product 001

meta_description

140–160 chars. Describe benefit + location + CTA.
Good: Buy Hikvision 4MP dome CCTV camera online. IP67, IR night vision. Free delivery in Chennai. Order now at Infysmart.

meta_keywords

5–10 comma-separated keywords.
hikvision dome camera, 4mp cctv, ip camera Chennai, outdoor security camera India

og_image optional

Upload a 1200×630 px image for WhatsApp/Facebook previews. Falls back to main product image if empty.
Image Rules
FormatJPG or WebP preferred. PNG for logos/transparent.
Min size800 × 800 px (square). 1200×1200 px ideal.
File sizeUnder 300 KB. Compress at tinypng.com if needed.
FilenameUse descriptive names: hikvision-4mp-dome-camera-front.jpg
Alt textFormula: [Brand] [Model] [Type] — Buy Online India
OrderFirst image = main product shot (white/grey background). Then: angles, installation, lifestyle.
Never: upload screenshots, watermarked images, or images with Hindi/Tamil text overlays. Google penalises poor product images.
Description Writing
• Put primary keyword in first 50 words
• Mention city/region naturally: "ideal for Chennai homes"
• Use bullet points for specs — easier for Google to parse
• No keyword stuffing — max 2–3 mentions of main keyword
• Include use cases: home, office, warehouse, factory
Pre-Publish QA Checklist
  • Product name is complete (Brand + Model + Type)
  • SKU filled & unique
  • Price & stock are correct
  • Short description under 120 chars
  • Long description 300+ words
  • At least 1 product image uploaded
  • Image alt text filled in
  • Category & Brand selected
  • Slug is clean (no uppercase, no spaces)
  • meta_title is 50–60 chars
  • meta_description is 140–160 chars
  • meta_keywords has 5–10 terms
  • Tags added (if meta_keywords empty)
  • og_image uploaded (optional but good)
  • Status set to Published
After publishing: Search site:infysmart.com/shop/[slug] in Google after 2–3 days to confirm indexing.
